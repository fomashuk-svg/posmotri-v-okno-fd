# Посмотри в окно

Проектная работа второго спринта курса Яндекс Практикума. Приложение показывает видео из окон в разных городах: можно искать ролики по городу и времени суток и переключать их по карточкам справа.

Разметка и скрипт были даны в заготовке. В проекте свёрстаны стили в `styles/style.css` по макету:

- раскладка страницы на Flexbox и Grid;
- кастомное текстовое поле и чекбоксы через псевдоэлементы;
- состояния `:hover`, `:active` и `:focus-visible` у кнопок, карточек и элементов формы;
- обрезка длинных заголовков и описаний (`text-overflow`, `line-clamp`);
- позиционирование прелоадеров над блоком видео и списком карточек.

## Технологии

HTML, CSS (Flexbox, Grid, логические свойства, псевдоклассы и псевдоэлементы), JavaScript (заготовка).
